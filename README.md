# Simple Arithmetic Calculator

A functional web-based calculator that balances modern UI aesthetics with advanced state logic. This project focuses on solving common calculation edge cases, such as operator switching, mathematical precision, and smart display resets.


## 🛠️ Built With

* **HTML5**: Structured with semantic elements for accessibility.
* **CSS3**: Styled using advanced layout techniques including **Flexbox**.
* **JavaScript (ES6)**: Powered by vanilla JS for state management, event delegation, and mathematical logic without external libraries.
